# POC tuiles

Prototype jetable pour valider le modèle de tuile paramétrée, les règles d'assemblage et la
génération de pistes (`docs/specs-fonctionnelles.md`, 10.2). Terrain seul : la voiture du POC 1
n'y roule pas, ce sera le POC 3. Voir `TODO.md` pour l'avancement.

## Lancer

```
make install
make test
npm run dev
```

Ouvrir http://localhost:5174.
